# BHOJORA — Food Delivery + Trust Platform

A Kolkata-first food delivery marketplace with customer, restaurant,
delivery, independent inspection and administration experiences.

## Product pillars

1.  Delivery convenience
2.  Evidence-backed trust and transparency
3.  Human-supervised AI intelligence

## Repository structure

Only `docs/`, `client/`, and `server/` at root. - `docs/`: product,
design, architecture, execution, security and checkpoint documents -
`client/`: web/mobile applications and shared packages - `server/`: API,
workers, integrations and tests

## Getting started

Read `docs/02-EXECUTION-AGENTS/SETUP.md` and `PLAN.md`. Do not install
all dependencies at once. Start at Checkpoint 00.

## Current status

Planning and specification baseline. No application code, payment
provider, domain, legal approval or production infrastructure is implied
by these documents.

## Non-negotiable

Independent platform assessments are not government certifications.
Payment status must be verified server-side. AI cannot make final
food-safety decisions.
